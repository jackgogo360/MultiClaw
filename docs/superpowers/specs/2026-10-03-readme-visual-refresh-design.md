## 范围

## 视觉方向

用户提供的两张图片是视觉参考，不作为编辑对象或复制素材。宣传图采用第一张
参考的亮色卡片与彩色模块；架构图采用第二张参考的深色背景、发光边框与清晰
分层。与全部深色方案相比，混合方案区分宣传和技术内容；与全部亮色相比，
架构图的彩色分层更突出。文字以中文为主，保留项目名与必要技术术语。

## 宣传图

新增 `docs/assets/multiclaw-capabilities.png`，宽幅原创信息图，四组功能卡片：
子 Agent/Team、持久化工作流、隔离写入、租户安全。底部表示模型、内置工具/MCP、
SQLite 或 MySQL 等支撑能力。保留开发阶段声明，避免生产成熟度、集群、移动端、
外部渠道、动态心跳代理、未经验证计费能力等宣传。

## 架构图

新增 `docs/assets/multiclaw-architecture.svg`，使用可编辑原生矢量绘图，从上到下五层：Web 交互，API/认证，
Agent 编排，工具/治理，持久化与执行环境。TenantContext 表示跨层作用域，
SSE 表示状态返回，成员 worktree 与主项目之间标明审阅后应用。SQLite 与 MySQL
必须用“或”连接，不表达双写。MCP 为主运行时集成，不画成成员运行时开放 MCP。
部署边界明确为单进程、单机，不表达多副本集群。
